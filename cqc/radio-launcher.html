Install and use uConsole Radio

Run python3 cqc/install-launcher.py as the normal desktop user on the configured CM4/AIO V2 uConsole. Installation backs up the previous launcher and starts no radio. Optional apps and their services must already be installed. Keep the checkout at its installed path for these local guides.
